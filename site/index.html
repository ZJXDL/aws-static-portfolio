Each number counts the mines in the eight squares around it. Use those clues to decide what’s safe.

  2. 02

  3. 03

    Mark the danger. Flag suspected mines, then open every safe square to win.

BEHIND THE GAME

This game is a static website hosted on AWS. CloudFront serves it over HTTPS from a private S3 bucket; OpenTofu defines the infrastructure, and GitHub Actions publishes updates.

How the site is deployed

A push to main starts a GitHub Actions workflow. AWS verifies the workflow with OIDC and grants temporary, limited credentials to upload the site and clear the CloudFront cache. The workflow cannot change the AWS infrastructure.
